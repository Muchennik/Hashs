# WifiCracker

Офлайн-перебор WPA/WPA2-PSK по словарю прямо на Android: берёт файлы от
**wifite** (PMKID и рукопожатия) и прогоняет словарь. Только для своих
сетей или с письменного разрешения владельца.

## Что ест
- `.hc22000` / `.22000` (hashcat 22000, подтипы 01 PMKID и 02 handshake)
- `.16800` (старый PMKID)
- `.cap` / `.pcap` / `.pcapng` — сам достаёт SSID (из beacon), PMKID (M1) и
  рукопожатие (M1+M2). Нужен хотя бы один beacon с именем сети в дампе.

## Как собрать APK (без локальной установки)
1. Залей проект в репозиторий GitHub (ветку/репо — любой).
2. Открой вкладку **Actions** → workflow **build-apk** запустится сам на push
   (или запусти вручную через *Run workflow*).
3. По завершении скачай артефакт **WifiCracker-debug-apk** — внутри
   `app-debug.apk`. Это debug-сборка, подписана debug-ключом, ставится как есть
   (разреши установку из неизвестных источников).

## Как собрать в Android Studio
Открой папку проекта, дай Gradle синхронизироваться (враппер-jar подтянется
автоматически), затем Build → Build APK(s).

## Как пользоваться
1. Кнопка 1 — выбери capture (.hc22000 или .cap от wifite).
2. Кнопка 2 — выбери словарь (обычный .txt, по паролю на строку, 8–63 симв.).
3. Старт. Прогресс и найденные пароли — в логе.

## Производительность
Крипто на `javax.crypto`, многопоточно по числу ядер. PBKDF2-HMAC-SHA1 4096 —
штука тяжёлая, так что это для учёбы и небольших словарей, не замена hashcat на
GPU. Для серьёзных словарей гоняй hashcat на ПК (режим 22000).
